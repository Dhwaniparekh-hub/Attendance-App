Abstract:
Attendance App is used for seeing the regularity of the student attending the class for any educational institutions. It enables the teachers to maintain the record of students present or absent in their class for a whole academic year.
Functionalities:
•	Add any number of classes along with the subject name.
•	Add Student’s name and roll number to the class.
•	 Mark the student as present “P” or Absent “A” in the class.
•	Change the dates.
•	Add a new student.
•	Save the class to database.
•	Save the attendance taken on a particular date in the database.
•	View attendance sheet of the whole month.
Tools and Technologies used:
•	Android Studio
•	Java
